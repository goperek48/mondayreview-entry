The funniest one-line review of my own Monday, for make.fun's "Monday, Reviewed in One Line" bounty ($2, top 5). One line, under 200 characters, and nothing else.

## The line

> My Monday had the plot of a loading screen and the battery life of a phone at 2% — somehow it still took all day.

113 characters, one line.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `entry.txt` in the output directory — a single line, no trailing newline.
